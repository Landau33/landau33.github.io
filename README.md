# Tu Yuang · Personal Homepage

Source for my personal homepage, published with GitHub Pages at
[`https://landau33.github.io`](https://landau33.github.io).

A single-page site (name, bio, experience, selected projects, awards, and
contact) with light/dark theme support and no build step — just static HTML,
CSS, and a little JavaScript.

## Project structure

```
.
├── index.html            # Page content: hero, about, experience, projects, awards, contact
├── 404.html              # Custom not-found page
└── assets/
    ├── css/style.css     # Colors and layout
    ├── js/main.js        # Theme toggle, copy-email, current year
    ├── img/              # Avatar and images
    └── docs/             # CV (PDF)
```

## Deploy

This repo is served directly by GitHub Pages — no build required.

1. Create a repo named `<username>.github.io`.
2. Push the contents of this folder to the repo root (don't nest it in a subfolder).
3. Wait 1–2 minutes, then visit `https://<username>.github.io`.

To use a custom domain, add a `CNAME` file at the repo root containing the domain (optional).

## Customize

- `index.html` — text content (name, bio, links, projects)
- `assets/css/style.css` — colors and typography
- `assets/js/main.js` — dark mode and small interactions
